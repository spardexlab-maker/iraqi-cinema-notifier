# Iraqi Cinema 24/7 Telegram Notifier 🎬

تطبيق يعمل على مدار 24 ساعة لمراقبة **Iraqi Cinema** (`iraqicinema.net`) وإرسال إشعار فوري على **تيليجرام** عند فتح الحجز لأي فلم جديد، مع ذكر **أسماء السينمات المتوفرة** و**أوقات العرض** و**عدد المقاعد المتاحة**.

---

## المميزات
- مراقبة تلقائية 24/7 كل 5 دقائق (قابل للتعديل).
- إشعار فوري عند انتقال أي فلم إلى قائمة الحجز المفتوح مع:
  - اسم الفلم والمدة والتاريخ.
  - جميع فروع السينما المتوفر بها الفلم (المنصور، مول بغداد، مول العراق، زيونة، الحارث، إلخ).
  - أوقات العرض ونوع الصالة (`REG`, `VIP`, `MAX`, `IMAX`, `Hey Led`) وعدد المقاعد المتبقية.
  - رابط مباشر لصفحة الحجز.
- أوامر تفاعلية داخل بوت تيليجرام:
  - `/start` — تفعيل الإشعارات ومعرفة الـ Chat ID الخاص بك.
  - `/now` — عرض جميع الأفلام المتاحة للحجز حالياً.
  - `/now اسم الفلم` — عرض السينمات والأوقات لفلم معين.
  - `/check` — فحص فوري للأفلام الجديدة.
  - `/status` — عرض حالة النظام وآخر فحص.
  - `/stop` — إيقاف الإشعارات.
- قاعدة بيانات `SQLite` لحفظ الأفلام المسجلة وعدم تكرار الإشعارات عند إعادة التشغيل.

---

## خطوات التشغيل

### 1. إنشاء بوت تيليجرام
1. افتح تيليجرام وابحث عن `@BotFather`.
2. أرسل `/newbot` واتبع الخطوات للحصول على `TELEGRAM_BOT_TOKEN`.

### 2. إعداد ملف `.env`
انسخ `.env.example` إلى `.env` وضع التوكن الخاص بك:
```env
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
TELEGRAM_CHAT_ID=
CHECK_INTERVAL_MINUTES=5
BRANCH_FILTER=
```
> ملاحظة: يمكنك ترك `TELEGRAM_CHAT_ID` فارغاً ثم إرسال `/start` للبوت بعد تشغيله ليشترك حسابك تلقائياً، أو وضع معرّف المحادثة/القناة مباشرة.
> إذا أردت متابعة سينمات محددة فقط، اكتب أسماءها في `BRANCH_FILTER` مثل: `Mansour,Iraq Mall,Baghdad`.

### 3. التشغيل على Windows
اضغط مرتين على `run.bat` أو شغّل:
```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
python -m app.main
```

### 4. التشغيل 24/7 على السيرفر أو Docker (موصى به للعمل المستمر بدون إطفاء الحاسبة)
```bash
docker compose up -d --build
```
أو يمكنك رفعه على أي خدمة استضافة مجانية/رخيصة تدعم Docker أو Python مثل **Railway** أو **Render** أو أي **VPS** ليعمل 24 ساعة حتى لو كانت حاسبتك مغلقة.
